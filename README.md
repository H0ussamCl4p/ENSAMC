# ENSAMC

Course notes, exercises, lab work (TP) and solutions shared by students, for students. Everything is sorted by cycle, program and module so you can find what you need quickly.

This is a student project, not an official one. Solutions are written by students, so double-check them with your teachers.

## Ensamien Parrainage

This repo is part of **Ensamien Parrainage**, the mentoring program where older students help newer ones: course resources, advice and support through the first years.

Follow us on [LinkedIn](https://www.linkedin.com/company/ensamien-parrainage/posts/).

## Structure

```
API/      integrated preparatory cycle (api1, api2)
CI/       engineering cycle (common first year, then one folder per program)
Master/   master's programs
```

Inside each module: `cours/` (lessons), `td/` (tutorials), `tp/` (lab work), `exercices/` and `projet/`. Files are mostly in French, like the courses.
