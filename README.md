# ENSAMC

Cours, TD, TP et corrections de l'[ENSAM Casablanca](https://www.ensam-casa.ma/), rangés comme la formation initiale de l'école. Ce n'est pas un dépôt officiel : les corrections sont faites par des étudiants, vérifiez avec vos profs.

```
API/      cycle préparatoire
CI/       cycle ingénieur
Master/   masters
```

Chaque module suit la même forme : `cours/`, `td/`, `tp/`, `projet/`.
