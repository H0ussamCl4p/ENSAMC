# ENSAMC

Cours, TD, TP et corrections de l'[ENSAM Casablanca](https://www.ensam-casa.ma/), rangés comme la formation initiale de l'école.

Ce n'est pas un dépôt officiel. Les corrections sont faites par des étudiants, vérifiez avec vos profs.

## Structure

```
API/      cycle préparatoire (api1, api2)
CI/       cycle ingénieur (tronc-commun-1a, cs2c, iagi, gsi, gsmi, gem, gmaa, msei)
Master/   ti, bdio, idms
```

Dans chaque filière : `semestre/module/` puis `cours`, `td`, `tp` ou `projet`.

## Contenu

- API1 : [algorithmique](API/api1/algorithmique/), [programmation C](API/api1/programmation-c/)
- API2 : [analyse numérique](API/api2/analyse-numerique/), [MATLAB](API/api2/matlab/)
- CI, 1ère année (toutes filières) : [Python pour tous](CI/tronc-commun-1a/python-pour-tous/)
- CS2C S1 : [structures de données](CI/cs2c/s1/structures-donnees-algo-avancee/), [SQL](CI/cs2c/s1/ingenierie-systemes-information/)
