# Ressources CS2C

Cours et outils en ligne gratuits, rangés par sujet.

## Linux

- [Introduction to Linux (LFS101)](https://training.linuxfoundation.org/training/introduction-to-linux/), Linux Foundation : cours gratuit en ligne, à son rythme, avec exercices pratiques (en anglais).

## Réseaux et sécurité web

- [Hacksplaining](https://www.hacksplaining.com/lessons) : leçons interactives sur les failles web : injection SQL, XSS, CSRF, contrôle d'accès, SSRF... (en anglais).

## Cloud

- [L'Cloud Bdarija](https://youtube.com/playlist?list=PLG0m2gJQx_J2O40dO5C-_1i8htLXxbznr) : playlist YouTube sur le cloud computing, en darija.

## Structures de données (piles et files)

- [Les piles et les files](https://sdz.tdct.org/sdz/les-piles-et-les-files-4.html) : tutoriel en C de l'ancien Site du Zéro (archive ; le navigateur peut signaler un certificat expiré).
- [Les piles et les files en langage C](https://www.studocu.com/row/document/universite-de-sousse/commande-des-machines/les-piles-et-les-files-en-langage-c/17168376) : cours sur Studocu (inscription parfois demandée).

## Systèmes d'information (Merise)

- [QCM sur le MCD](https://mrproof.blogspot.com/2010/09/qcm-corrige-mcd-exercice-mcd-analyse.html) et son [corrigé](https://mrproof.blogspot.com/2010/09/corrige-qcm-mcd-exercice-mcd-analyse.html) : individus, relations et informations d'un modèle conceptuel de données.
