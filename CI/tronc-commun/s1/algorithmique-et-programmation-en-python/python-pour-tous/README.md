## TP

| TP | Contenu |
|---|---|
| [TP1](tp/tp1/) | fonctions sur les chaînes : mots, majuscules, palindrome |
| [TP2](tp/tp2/) ([énoncé](tp/tp2/enonce.pdf)) | opérations de base, suites, plus grand diviseur, conversion en binaire |
| [TP3](tp/tp3/) | menu avec `match`, distributeur de billets |
| [TP4](tp/tp4/) | occurrences, deux plus grands éléments, palindrome, gestion de stock avec NumPy et matplotlib |
| [TP5](tp/tp5/) ([énoncé](tp/tp5/enonce.pdf)) | dictionnaires : occurrences, positions, anagrammes, notes par module, chiffrement |

Lancer un exercice : `python tp/tp3/ex2-distributeur.py`. Le TP4 ex5 a besoin de `pip install numpy matplotlib`.
